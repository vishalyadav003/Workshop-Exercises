# Dependency Inventory

The inventory describes direct runtime dependencies declared by this project. Installed version is the pinned target; confirm the actual environment with `python -m pip show python-dotenv` after installation.

| Package Name | Installed Version | Purpose | License |
|---|---:|---|---|
| python-dotenv | 1.0.1 | Loads local `.env` configuration into the process environment. | BSD-3-Clause |

The Python standard library modules used by the project (including `logging`, `unittest`, `pathlib`, and `importlib.metadata`) are included with Python and are not separately installed packages.
