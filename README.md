# Local web apps

Each folder is a separate web app with its own visual design. Run them from the listed folder; all can stay open together on different local ports.

| Project folder | Start command | Open in browser |
| --- | --- | --- |
| `exercise1.1` | `python app.py` | `http://127.0.0.1:5101` |
| `exercise1.2` | `python app.py` | `http://127.0.0.1:5102` |
| `exercise2.1` | `python webapp.py` | `http://127.0.0.1:5201` |
| `exercise2.2` | `python app.py` | `http://127.0.0.1:5202` |
| `exersice3.1` | `python webapp.py` | `http://127.0.0.1:5301` |
| `esercise3.2` | `python app.py` | `http://127.0.0.1:5302` |
| `exercise4.1` | `python app.py` | `http://127.0.0.1:5401` |
| `exercise4.2` | `python app.py` | `http://127.0.0.1:5402` |

Install the folder's `requirements.txt` first where one is provided. The interfaces are built with HTML, CSS and JavaScript; the Flask apps keep their existing Python data and validation logic. The two CSV dashboards work in the browser and read their bundled sample CSVs.
